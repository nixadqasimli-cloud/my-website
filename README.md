NKGen AI 🚀
Süni İntellektlə Vebsayt Konstruktoru və Canlı Önizləmə Platforması

NKGen AI — istifadəçilərə sadə mətn komutları (promptlar) vasitəsilə saniyələr içərisində tam funksional, müasir və responsiv vebsaytlar yaratmağa imkan verən qabaqcıl frontend vebsayt konstruktorudur. Layihə tamamilə müasir veb texnologiyaları əsasında qurulub və birbaşa brauzerdə işləyir.

✨ Əsas Xüsusiyyətlər
🤖 Süni İntellektlə Generasiya: İstifadəçi təsvirlərinə əsasən avtomatik olaraq təmiz, oxunaqlı və işlək HTML/CSS/JS kodu generasiya edir.

🛠️ AI Co-Pilot (Canlı Redaktə): Hazır olan vebsayt üzərində istədiyiniz dəyişiklikləri (məsələn, rənglərin dəyişdirilməsi, yeni bölmələrin əlavə olunması) süni intellekt vasitəsilə birbaşa tətbiq edin.

📱 Çoxrəqəmli Önizləmə (Responsive Preview): Saytınızın masaüstü (Desktop), planşet (Tablet) və mobil (Mobile) ekranlarda necə görünəcəyini real vaxt rejimində yoxlayın.

💻 Daxili Kod Redaktoru: Yaradılan vebsaytın kodunu birbaşa daxili redaktorda görüb redaktə edə bilərsiniz.

🌐 Canlıya Atma (Deploy) Dəstəyi: Hazırladığınız saytları .html formatında yükləyin və ya bir kliklə Netlify kimi platformalarda canlıya çıxarın.

🌍 Çoxdilli Dəstək: Azərbaycanca, Türkçe və İngilis dili dəstəyi.

👤 İstifadəçi və Kredit Sistemi: Demo qeydiyyat/giriş sistemi və generasiya üçün kredit idarəetmə mexanizmi.

🛠️ İstifadə Olunan Texnologiyalar
HTML5 & CSS3 (Tailwind CSS prinsipləri və Grid/Flexbox arxitekturası)

Vanilla JavaScript (ES6+)

Claude API (Anthropic) – Süni intellekt mətn və kod generasiyası üçün

Font Awesome & Google Fonts (Plus Jakarta Sans)

🚀 Necə İşlətmək / Quraşdırmaq olar?
Bu layihə heç bir mürəkkəb server (Node.js/npm) quraşdırması tələb etmir, çünki tək fayldan ibarət təmiz frontend tətbiqidir.

Bu repozitoriyadakı index.html faylını kompüterinizə endirin.

Kodun daxilindəki Claude API açarı hissəsini öz açarınızla əvəz edin:

JavaScript
const CLAUDE_API_KEY = "BURAYA_KODUNuzu_YAZIN";
index.html faylını istənilən brauzerdə (Chrome, Edge, Firefox və s.) açaraq dərhal istifadə etməyə başlayın!

📌 GitHub Pages ilə Canlıya Çıxarmaq (Deploy)
Layihənizi internetdə hər kəsə göstərmək üçün:

GitHub-da yeni bir Repository yaradın (məsələn: nkgen-ai).

index.html faylını bura yükləyin (uploading an existing file).

Repository bölməsindən Settings > Pages səhifəsinə keçin.

Branch hissəsini main seçib Save düyməsinə basın. Bir neçə dəqiqə ərzində saytınız üçün veriləcək github.io linkindən istifadə edə bilərsiniz!
